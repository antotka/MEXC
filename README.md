# Бонус-калькулятор для Telegram Ads

Файлы: `bot.py` (бот + сервер), `index.html` (Mini App), `requirements.txt`.

## Запуск на Render (Web Service)
1. Залейте папку на GitHub.
2. Render → New → Web Service. Build: `pip install -r requirements.txt`. Start: `python bot.py`.
3. Переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather
   - `WEBAPP_URL` — https-адрес сервиса на Render (например https://mybot.onrender.com)
   - `REF_LINK` — ваша реферальная ссылка
   - `PROMO_URL` — официальная страница акции (необязательно, но лучше указать)
4. Откройте бота, нажмите /start. На бесплатном тарифе Render сервис засыпает: для рекламы возьмите платный или пингуйте /health.

## Настройка процентов
В `index.html` массив `ANCHORS`: пары [сумма $, процент]. Кривая плавно проходит через эти точки,
поэтому ступенек нет. Поставьте реальные цифры из условий акции.

## Перед запуском рекламы
Проверьте правила Telegram Ads для финансовых и крипто-тематик и не пишите в объявлении «гарантировано».
